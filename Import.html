Excel ડેટા એન્ટ્રી મહત્વપૂર્ણ સૂચનાઓ

ફાઇલ ભરતા પહેલા નીચેની સૂચનાઓ ખાસ ધ્યાને લેશો:

Excel [Enable Editing] બટન: ફાઇલ ખોલતી વખતે જો ઉપર પીળી પટ્ટીમાં [Enable Editing] (સંપાદન સક્ષમ કરો) બટન દેખાય તો સૌથી પહેલાં તેના પર ક્લિક કરવું, જેથી ડેટા એન્ટ્રી, ડ્રોપડાઉન અને શીટ બટન સક્રિય થાય.
લાલ કલરના બોક્સ / હેડર ફરજિયાત છે: રોલ નં, જી.આર. નં, વિદ્યાર્થીનું નામ, જન્મ તારીખ, જાતિ, ધોરણ, વર્ગ, શ્રેણી, UID અને મોબાઈલ નંબર ભરવા ફરજિયાત (Compulsory) છે.
બાલવાટિકા અને ધોરણ (Standard): ધોરણ 1 થી 8 અથવા બાલવાટિકાના વિદ્યાર્થી માટે ડ્રોપડાઉનમાંથી 'BV' (અથવા 0) પસંદ કરવું. આયાત વખતે સિસ્ટમ આપોઆપ તેને બાલવાટિકામાં સેવ કરી લેશે.
જન્મ તારીખ ફોર્મેટ: તારીખ હંમેશા DD-MM-YYYY (દા.ત. 15-06-2015) ના રૂપમાં જ લખવી.
Paste as Values: અન્ય ફાઇલમાંથી ડેટા સીધો Paste ન કરતાં 'Paste as Values' (123) કરવો, જેથી Dropdowns અને ફોર્મેટિંગ ન બગડે.
ચોકસાઈ: લીલા કલરવાળા હેડર (માતાનું નામ, વાલીનું નામ, સરનામું) વૈકલ્પિક છે. તમામ માહિતી પૂરી ચોકસાઈપૂર્વક ભરવી.
સમજાઈ ગયું (OK) - ડાઉનલોડ કરો

SSA પોર્ટલ પરથી Excel ફાઇલ ડાઉનલોડ કરવાની રીત સરળ સ્ટેપ્સ

Child Tracking System (CTS) માંથી વિદ્યાર્થીઓની યાદી ડાઉનલોડ કરીને અહીં Import કરો

1

સ્ટેપ ૧ : SSA ગુજરાત પોર્ટલ ખોલો અને લૉગિન કરો

🔗 SSA પોર્ટલ ખોલો (Click Here)

સૌથી પહેલાં બ્રાઉઝરમાં https://www.ssgujarat.org/CTELogin.aspx ખોલો. ત્યાં તમારી શાળાનો U-DISE કોડ / User ID અને Password દાખલ કરીને Login બટન પર ક્લિક કરો.

2

સ્ટેપ ૨ : ડાબી બાજુના મેનુમાંથી 'Home' પર ક્લિક કરો

સફળતાપૂર્વક લૉગિન થયા પછી ડાબી બાજુ આપેલી MAIN NAVIGATION વાળી બ્લુ પટ્ટીમાં સૌથી ઉપર આપેલા Home મેનુ પર ક્લિક કરો (નીચે સ્ક્રીનશોટમાં ઓરેન્જ બોક્સ જુઓ).

સ્ક્રીનશોટ પ્રમાણે: ડાબી બાજુ 'Home' બટન પર ક્લિક કરો
3

સ્ટેપ ૩ : 'TOTAL STUDENTS' કાર્ડમાં 'View Details ➔' પર ક્લિક કરો

Home પેજ પર KEY METRICS માં સૌથી પહેલું વાદળી (Navy Blue) કાર્ડ "TOTAL STUDENTS / કુલ વિદ્યાર્થીઓ" દેખાશે. તે કાર્ડની નીચે આપેલા "View Details ➔" બટન પર ક્લિક કરો.

સ્ક્રીનશોટ પ્રમાણે: 'TOTAL STUDENTS' કાર્ડની અંદર 'View Details' પર ક્લિક કરો
4

સ્ટેપ ૪ : ઉપર જમણી બાજુ 'Export to Excel' બટન પર ક્લિક કરો

હવે તમારી શાળાના તમામ વિદ્યાર્થીઓનું STUDENT WISE LIST · DETAILED REPORT ખૂલશે. તેમાં ઉપર જમણી બાજુ આપેલા લીલા રંગના "Export to Excel" બટન પર ક્લિક કરતાં જ તમારી શાળાની Excel ફાઇલ તમારા કમ્પ્યુટર / મોબાઇલમાં ડાઉનલોડ થઈ જશે!

સ્ક્રીનશોટ પ્રમાણે: ઉપર જમણી બાજુ લીલા રંગના 'Export to Excel' બટન પર ક્લિક કરો
5

સ્ટેપ ૫ : હવે ડિજિટલ શાળામાં આ ફાઇલ અપલોડ કરી દો

હવે આ પેજ પર આવીને નીચે આપેલા બોક્સમાં તે ડાઉનલોડ થયેલી Excel ફાઇલ સિલેક્ટ કરો અને "SSA ડેટા આયાત કરો" બટન દબાવો. સિસ્ટમ આપોઆપ તમામ વિદ્યાર્થીઓના નામ, ગુજરાતી નામ, GR નંબર, ધોરણ, જન્મ તારીખ વગેરે તૈયાર કરી આપશે!
